# Примеры образов Docker
В данном репозитории представлены примеры настроенных образов для развёртывания в Docker приложений, написанных на разных языках и имеющих разную архитектуру

**Архив имеет следующее содержимое:**
- calc-java - Образ для запуска в Docker простого консольного приложения калькулятора написанного на Java
- calc-py - Образ для запуска в Docker простого консольного приложения калькулятора написанного на Python
- dart-calc - Образ для запуска в Docker простого консольного приложения калькулятора написанного на Dart
- game-java - Образ для запуска в Docker простого консольного приложения игры на угадывание числа написанного на Java
- rpsgame-py - Образ для запуска в Docker простого консольного приложения игры "камень-ножницы-бумага" написанного на Python
- site - Образ для запуска в Docker веб-сервера Nginx для размещение простого статического сайта
